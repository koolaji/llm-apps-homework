تمرین فصل Tool_use — تحلیلگر مالی هوشمند

🛠 تمرین اول: طراحی Tool استاندارد برای دریافت اطلاعات سهام

این نمرین پیش نیاز تمرین فصل بعدی نیز هست

هدف

نوشتن یک تابع پایتون که اطلاعات یک نماد بورسی را از TSETMC می‌گیرد و آن را طوری برمی‌گرداند که یک LLM بدون ابهام بتواند از آن به‌عنوان Tool در Function Calling استفاده کند.

پیش‌نیازهای فنی

یکی از این دو مسیر را انتخاب کنید و در گزارش نهایی مشخص کنید کدام را استفاده کرده‌اید:

گزینه نصب یادداشت
کتابخانه pytse-client pip install pytse-client ساده‌تر، برای دیتای تاریخی و لحظه‌ای مناسب است
API غیررسمی TSETMC (tsetmc-api یا فراخوانی مستقیم endpoint) بسته به کتابخانه نیاز به بررسی مستندات دارد

الزامات دقیق تابع

امضای تابع (اجباری):

def get_stock_info(symbol: str) -> dict:
    """
    اطلاعات لحظه‌ای یک نماد بورسی ایران را از TSETMC بازمی‌گرداند.

    Args:
        symbol (str): نماد سهم به فارسی یا انگلیسی، دقیقاً همانطور که در
            TSETMC ثبت شده است. مثال: "فولاد"

    Returns:
        dict: دیکشنری با کلیدهای زیر:
            - symbol (str): نماد سهم
            - name (str): نام کامل شرکت
            - last_price (float): آخرین قیمت معامله‌شده (تومان)
            - price_change_percent (float): درصد تغییر نسبت به روز قبل
            - volume (int): حجم معاملات
            - market_cap (float | None): ارزش بازار در صورت موجود بودن
            - last_update (str): زمان آخرین به‌روزرسانی به فرمت ISO 8601

    Raises:
        ValueError: اگر نماد وارد‌شده در TSETMC یافت نشود.
    """

۴ چیزی که حتماً باید در کد شما دیده شود:
1. Type Hints روی ورودی و خروجی (نه فقط در docstring، در امضای تابع هم).
2. Docstring به فرمت Google Style دقیقاً مثل نمونه بالا (Args / Returns / Raises).
3. اعتبارسنجی ورودی — اگر نماد پیدا نشد، ValueError بدهید، نه اینکه برنامه کرش کند.
4. یک Schema جدا برای همین تابع به فرمت JSON Schema . نمونه:

{
  "name": "get_stock_info",
  "description": "دریافت اطلاعات لحظه‌ای یک نماد بورسی ایران از TSETMC",
  "input_schema": {
    "type": "object",
    "properties": {
      "symbol": {
        "type": "string",
        "description": "نماد سهم، مثلاً 'فولاد' یا 'خودرو'"
      }
    },
    "required": ["symbol"]
  }
}

  1. تحلیل تکنیکال یک نماد را از LLM بپرسید و پرامپت را طوری بنویسید که حتما از این ابزار استفاده گردد.

  2. جست و جو در اینترنت نیز ممکن است به تحلیل بهتر کمک کند؛ یک ابزار برای سرچ اخبار این نماد در اینترنت نیز بنویسید (اختیاری)

معیار قبولی (Checklist تحویل تمرین اول)

  • تابع با get_stock_info("فولاد") بدون خطا اجرا می‌شود و dict برمی‌گرداند
  • وقتی نماد نامعتبر داده می‌شود (مثلاً "XYZ123") خطای ValueError با پیام مشخص می‌دهد
  • فایل schema.json جدا شامل JSON Schema بالا وجود دارد
  • یک تست کوچک (۳-۴ خط) نشان می‌دهد که خروجی تابع را مستقیماً می‌شود به یک پیام Function Calling در OpenAI/Claude API پاس داد
  • نوشتن یک پرامپت برای تحلیل تکنیکال یک نماد و وادار کردن LLM به استفاده از این ابزار با توحه به سوال.
