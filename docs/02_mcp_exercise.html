الزامات دقیق تابع

امضای تابع (اجباری):

def get_stock_info(symbol: str) -> dict:
    """
    اطلاعات لحظه‌ای یک نماد بورسی ایران را از TSETMC بازمی‌گرداند.

    Args:
        symbol (str): نماد سهم به فارسی یا انگلیسی، دقیقاً همانطور که در
            TSETMC ثبت شده است. مثال: "فولاد"

    Returns:
        dict: دیکشنری با کلیدهای زیر:
            - symbol (str): نماد سهم
            - name (str): نام کامل شرکت
            - last_price (float): آخرین قیمت معامله‌شده (تومان)
            - price_change_percent (float): درصد تغییر نسبت به روز قبل
            - volume (int): حجم معاملات
            - market_cap (float | None): ارزش بازار در صورت موجود بودن
            - last_update (str): زمان آخرین به‌روزرسانی به فرمت ISO 8601

    Raises:
        ValueError: اگر نماد وارد‌شده در TSETMC یافت نشود.
    """

۴ چیزی که حتماً باید در کد شما دیده شود:
1. Type Hints روی ورودی و خروجی (نه فقط در docstring، در امضای تابع هم).
2. Docstring به فرمت Google Style دقیقاً مثل نمونه بالا (Args / Returns / Raises).
3. اعتبارسنجی ورودی — اگر نماد پیدا نشد، ValueError بدهید، نه اینکه برنامه کرش کند.
4. یک Schema جدا برای همین تابع به فرمت JSON Schema (که در تمرین دوم مستقیم در MCP استفاده می‌شود). نمونه:

{
  "name": "get_stock_info",
  "description": "دریافت اطلاعات لحظه‌ای یک نماد بورسی ایران از TSETMC",
  "input_schema": {
    "type": "object",
    "properties": {
      "symbol": {
        "type": "string",
        "description": "نماد سهم، مثلاً 'فولاد' یا 'خودرو'"
      }
    },
    "required": ["symbol"]
  }
}

معیار قبولی (Checklist تحویل تمرین اول)

  • تابع با get_stock_info("فولاد") بدون خطا اجرا می‌شود و dict برمی‌گرداند
  • وقتی نماد نامعتبر داده می‌شود (مثلاً "XYZ123") خطای ValueError با پیام مشخص می‌دهد
  • فایل schema.json جدا شامل JSON Schema بالا وجود دارد
  • یک تست کوچک (۳-۴ خط) نشان می‌دهد که خروجی تابع را مستقیماً می‌شود به یک پیام Function Calling در OpenAI/Claude API پاس داد

🚀 تمرین دوم: MCP Server مالی با چند ابزار ترکیبی

هدف

ساخت یک MCP Server که حداقل ۳ Tool واقعی داشته باشد و طراحی یک پرامپت که مجبور می‌کند مدل چند Tool را با هم ترکیب کند تا به یک تحلیل درست برسد — نه اینکه فقط یک Tool صدا بزند و تمام.

نکته: لیست‌کردن ابزارهای سرور (tools/list) بخشی از خود پروتکل MCP است و توسط SDK/کتابخانه‌ای که استفاده می‌کنید (مثل mcp پایتون) به‌صورت خودکار هندل می‌شود؛ نیازی نیست خودتان تابعی برای این کار بنویسید.

واژه‌نامه کوچک (برای کسانی که با بازار مالی آشنا نیستند)

اصطلاح توضیح ساده
انس (Ounce) طلا واحد وزن استاندارد جهانی برای طلا (تقریباً ۳۱.۱ گرم). قیمت جهانی طلا معمولاً به «دلار به ازای هر انس» بیان می‌شود، نه به گرم.
نرخ دلار قیمت هر دلار آمریکا بر حسب تومان/ریال. در ایران چند نرخ همزمان وجود دارد (نرخ آزاد بازار، نرخ نیمایی و ...)؛ برای این تمرین همان نرخی که API برمی‌گرداند کافی است.
نماد بورسی (Symbol) کد اختصاصی هر شرکت در بورس، مثلاً «فولاد» برای فولاد مبارکه.

Tool های الزامی (حداقل این سه، می‌توانید بیشتر هم اضافه کنید):

Tool منبع داده چه چیزی برمی‌گرداند
get_stock_info(symbol: str) TSETMC (همان تمرین اول) اطلاعات یک نماد بورسی ایران
get_gold_price() gold-api.com — رایگان، بدون نیاز به API Key قیمت جهانی هر انس طلا (XAU) به دلار
get_usd_rate() navasan.tech — نیاز به API Key رایگان (از طریق ربات تلگرام @navasan_contact_bot) نرخ دلار به تومان

میتوانید از APi های مالی و مرتبط دیگر استفاده کنید.
در این تمرین مهم است حداقل 2 ابزار دیگر جز ابزار مرتبط با بازیابی اطلاعات از TSETMC هم استفاده شود و با این ابزار به مدل اطلاعات بیشتری برای تحلیل مالی داده شود.

راهنمای فراخوانی این دو API (برای جلوگیری از سردرگمی):

# gold_price.py
import requests

def get_gold_price() -> dict:
    """
    قیمت لحظه‌ای جهانی طلا (هر انس، به دلار) را از gold-api.com برمی‌گرداند.

    Returns:
        dict: {"symbol": "XAU", "price_usd_per_ounce": float, "name": str}
    """
    response = requests.get("https://api.gold-api.com/price/XAU", timeout=10)
    response.raise_for_status()
    data = response.json()
    return {
        "symbol": data["symbol"],
        "price_usd_per_ounce": data["price"],
        "name": data.get("name", "Gold"),
    }

# usd_rate.py
import requests

NAVASAN_API_KEY = "YOUR_API_KEY"  # از ربات تلگرام @navasan_contact_bot بگیرید

def get_usd_rate() -> dict:
    """
    آخرین نرخ دلار آمریکا به تومان را از navasan.tech برمی‌گرداند.

    Returns:
        dict: {"usd_sell_toman": float, "last_update": str}
    """
    url = f"https://api.navasan.tech/latest/?api_key={NAVASAN_API_KEY}"
    response = requests.get(url, timeout=10)
    response.raise_for_status()
    data = response.json()
    # ساختار دقیق پاسخ را حتماً یک‌بار پرینت کنید و در مستندات navasan.tech چک کنید،
    # چون ممکن است بسته به پلن حساب شما کمی فرق داشته باشد
    usd_info = data["usd"]
    return {
        "usd_sell_toman": float(usd_info["value"]),
        "last_update": usd_info["date"],
    }

هر دو تابع را با همان قوانین تمرین اول (Type Hint + Docstring + Schema جدا) کامل کنید.

الزام کلیدی: پرامپت باید طوری نوشته شود که مدل نتواند بدون فراخوانی حداقل دو Tool به جواب برسد.

سناریوی تمرین: کاربر می‌پرسد «قیمت طلای داخلی الان تقریباً چقدره؟»

تو یک تحلیلگر بازار طلا هستی. برای پاسخ به سوال کاربر درباره «قیمت طلای داخلی»
دقیقاً این مراحل را طی کن و مراحل را حذف نکن:

۱. با ابزار get_gold_price قیمت جهانی هر انس طلا به دلار را بگیر.
۲. با ابزار get_usd_rate نرخ فعلی دلار به تومان را بگیر.
۳. با استفاده از فرمول زیر قیمت تقریبی هر گرم طلای ۱۸ عیار داخلی را حساب کن:
   قیمت هر گرم طلای ۲۴ عیار (تومان) = (قیمت انس ÷ 31.1) × نرخ دلار
   قیمت هر گرم طلای ۱۸ عیار = قیمت هر گرم طلای ۲۴ عیار × 0.75
۴. نتیجه را به همراه دو عدد خامی که از Tool ها گرفتی (انس جهانی و نرخ دلار)
   به فارسی و به‌صورت شفاف نمایش بده.

نکته: اگر هرکدام از دو Tool خطا داد یا داده برنگرداند، محاسبه را انجام نده
و صریحاً به کاربر بگو کدام داده در دسترس نبود.

چرا این پرامپت خوب است:
محاسبه نهایی به هر دو عدد وابسته است، پس مدل مجبور است هر دو Tool را صدا بزند — این دقیقاً همان چیزی است که یک MCP Server چند-ابزاره را معنادار می‌کند (نه صرفاً تزئینی).
